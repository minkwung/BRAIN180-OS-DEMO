# B180 · OS — 프론트엔드 프로토타입

MSC 브레인코칭 온라인 학습 프로그램의 UI/UX 및 데이터 흐름 프로토타입입니다. 순수 HTML/CSS/JavaScript 단일 파일(`b180-os-curriculum.html`, 약 4,400줄)로 작성되어 있으며, 별도 빌드 도구나 서버 없이 **브라우저에서 파일을 열기만 하면 바로 실행**됩니다.

## 실행 방법

- 로컬: `b180-os-curriculum.html`을 더블클릭하거나 브라우저로 드래그
- 배포: 정적 파일이므로 GitHub Pages / Netlify / Vercel 등 어디에도 그대로 올리면 동작합니다 (빌드 스텝 없음)

## 역할 (4개)

게이트 화면에서 로그인 후 아래 역할로 진입합니다. 한 세션(브라우저 탭) 안에서 역할을 자유롭게 바꿔가며 서로의 화면이 실시간으로 반영되는 것처럼 보이도록 만들어져 있습니다 — 실제로는 **모든 역할이 하나의 JS `state` 객체를 공유**하기 때문입니다 (아래 "구조" 참고).

| 역할 | 주요 기능 |
|---|---|
| 학생 | 커리큘럼 진행(4권×3편), STEP1~8 학습 흐름(퀴즈·읽기훈련·문장이해·사고의계단·다이어그램·독해문제·스피치·소크라테스 문답법), 레포트 쓰기, 정기 테스트 응시, 아바타/반려동물/방 꾸미기, 독서·지식 트리, 채팅 |
| 브레인코치(교사) | 실시간 모니터링, 학생 관리(MSC 유형·상급반 추천), 정기 테스트 배정·감독, 수업 자료 실시간 공유, 캘린더·알람, 공지사항, 학부모 채팅, 주간/정기 리포트 발송 |
| 학부모 | 자녀 학습 현황·성장 그래프·출석, 아바타/방 열람, 정기 테스트·주간 리포트 확인, 교사와 채팅 |
| 교재팀 | 책/텍스트 DB CRUD(본문 업로드 포함), 정기 테스트 문제 출제 |

## 구조

```
<script> 내부 대략적인 순서
├─ 데이터 상수: BOOK_META, TEXTS(책 12편 전체 원문/문항), MSC_TYPES, 각종 SHOP_ITEMS 등
├─ let state = {...}       ← 앱 전체의 단일 진실 공급원(single source of truth)
├─ 화면별 render*() 함수    ← state를 읽어 HTML 문자열을 만들고 #root.innerHTML에 주입
├─ 화면별 bind*() 함수      ← 방금 그린 DOM에 이벤트 리스너를 다시 연결
└─ render() / 최초 호출     ← 위 두 단계를 반복하는 매우 단순한 수동 렌더 루프
```

React 등 프레임워크 없이 "상태 변경 → innerHTML 전체 재작성 → 이벤트 재바인딩"을 직접 구현한 구조입니다. 실제 서비스로 전환할 때는 이 로직을 컴포넌트 기반 프레임워크(React/Vue)와 실제 백엔드 위로 옮기는 작업이 필요합니다.

## ⚠️ 실제 AI가 아니라 "시뮬레이션"인 부분

데모/설계 목적상 아래 기능들은 **실제 LLM·STT 호출 없이 규칙·템플릿으로 흉내** 낸 것입니다. 브리핑 시 반드시 안내가 필요합니다.

- `evaluateEssay()` — 글자수·연결어 유무 등 휴리스틱으로 점수 산출 (실제로는 LLM 첨삭 필요)
- 스피치 STT — 고정 문장을 "인식 결과"로 표시 (실제 STT 엔진 필요)
- `generateSocraticAnswer()` / `generateSocraticExtension()` — 본문 핵심어를 문장 템플릿에 끼워 넣는 방식 (실제로는 LLM이 학생 질문을 이해하고 답해야 함)
- `computeMSCProfile()` 등 — 학습 데이터 기반 규칙 계산 (실제로는 외부 검사 결과 연동 또는 별도 분석 엔진 필요)
- 다이어그램 의미관계 자동 판단 — 사전 정의된 관계 테이블 기반
